# FIF 口语 v1.0.0-beta.1

首个公开测试版，提供 PySide6 桌面客户端与本机 WebUI。

## 功能

- 多账号登录、图片验证码手动输入、账号参考音色管理。
- 默认 Edge TTS；保留 YourTTS、XTTS v2，本地模型按需单独下载。
- 已适配英文朗读题型的音频生成、真实评测、上传、提交和报告核对。
- 任务、课程、关卡三级队列，支持暂停、恢复与逐题进度保存。
- 应用、FFmpeg 和可选本地 TTS 环境的自动准备与诊断。
- `src/fif_oral/` 分包结构，`pyproject.toml`、`uv.lock` 与独立命令入口。

## 下载与启动

- Windows x64 源码版：下载 `fif-oral-1.0.0-beta.1-source.zip`，解压后运行 `setup.cmd`；桌面启动方式见 README。
- 已有 Python 3.11–3.13：安装 wheel；需要 WebUI 时使用 `[web]` 可选依赖。
- 附件包含 wheel、源码发行包、完整源码 ZIP 及 SHA-256 校验文件。

## 验证与限制

本地 106 项测试通过；测试中的部分远程服务使用模拟实现，不代表所有真实账号、题目或平台版本均已验证。

听力原生提交、t12 等题型尚未接入。WebUI 手工录音与失败题音频替换仍需使用桌面版。当前未提供 EXE 安装包；不承诺具体分数或长期接口兼容。

本项目仅供学习、研究与技术交流。请阅读 README 中的使用须知、隐私说明及第三方许可。源码与附件不包含用户账号、参考音色、生成录音、模型权重或运行数据。
