## 下载与启动

- Windows x64 源码版：下载 `fif-oral-1.0.0-beta.2-source.zip`，解压后运行 `setup.cmd`；桌面启动方式见 README。
- 已有 Python 3.11–3.13：安装 `fif_oral_desktop-1.0.0b2-py3-none-any.whl`；WebUI 使用 `[web]` 可选依赖。
- 附件包含完整源码 ZIP、wheel、源码发行包及 SHA-256 校验文件。

## 验证与限制

业务功能沿用 beta.1：支持桌面与本机 WebUI、多账号、Edge TTS / YourTTS / XTTS v2、已适配英文朗读题型和可恢复队列。

听力原生提交、t12 等题型尚未接入；WebUI 手工录音和失败题音频替换仍需使用桌面版。当前未提供 EXE 安装包，不承诺具体分数或长期接口兼容。

发行包排除用户账号、参考音色、录音、模型、日志和运行数据。`v1.0.0-beta.1` 的历史标签与附件保持不变。
