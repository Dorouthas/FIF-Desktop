# FIF 口语客户端

支持桌面版与本机 WebUI，提供多账号、参考音色管理、任务查询和本地音频挑战。默认 Edge TTS，同时支持 YourTTS 与 XTTS v2。

### 数据与隐私

- 登录所需凭据会通过 HTTPS 发送至 FIF 口语登录服务；客户端没有内置向项目维护者自建服务器上传账号库的功能。
- `data/accounts.json` 使用主密码派生密钥并加密保存。参考 WAV、生成录音、题目文本、评测报告和日志等其他本地文件不随账号库一并加密，请妥善保管 `data/`。
- 使用 Edge TTS 时，待合成文本会发送给微软在线语音服务。YourTTS、XTTS v2 的合成在本机进行；选择本地模型不等于评测与提交也离线。
- 在线评测会将参考文本和录音发送给平台指定的讯飞评测服务；挑战提交还会将录音及评测 XML 上传至平台指定的对象存储，并向 FIF 口语提交结果。
- 发布源码或反馈问题时，请移除账号密码、访问令牌、带鉴权参数的地址、学生身份信息及未获公开许可的音频；不要直接上传整个 `data/` 或原始抓包文件。

## 功能与使用流程

界面使用原生 PySide6，采用白色圆角面板、浅灰背景、黑色标题及蓝色强调的浅色主题。主题集中在 `src/fif_oral/ui/theme.py`；`src/fif_oral/resources/assets/` 中包含本项目绘制的箭头和勾选图标。后续打包 EXE 时需将该目录一并加入数据文件。

进入关卡详情，点击「本地答题」可以选择麦克风，逐题录音、试听和重录。应用将每道题的录音保存为本地 WAV，再次打开关卡时定位到首道未录题。平台成绩仍通过只读查询显示。

点击「音频挑战」，默认选择「自动生成音频」，然后点击「自动生成并提交」。新配置默认使用 Edge TTS 联网合成，无需下载大模型或导入参考 WAV；朗读文本会发送到微软语音服务。已有配置继续使用原来的引擎和单词策略。YourTTS、XTTS v2 均保留，可在「模型设置」选择；两者使用本地模型和账号参考音色。每题先生成候选、检查并评测；整关全部验收后才上传录音和对应 XML、提交结果并回查成绩。Edge 音频转换和录音修正需要 FFmpeg，可在「环境与下载」自动准备，也可手动选择 `ffmpeg.exe`。

也可以切换为「选择本地音频」，逐题选择 WAV、MP3 等文件后评测并提交。

## 整任务自动完成

在左侧任务树右键任意任务、课程或关卡，选择「全自动完成」。任务会查询全部课程与关卡，课程会查询全部关卡，关卡只处理自身；无需先展开任务树。窗口自动启动串行队列，可选择账号参考音色、模型设置与 FFmpeg，也可暂停后调整配置并继续。

每关复用音频挑战的生成、候选预算、评测、上传和报告核对流程。默认跳过平台分数已达到设置目标的关卡；取消勾选后会处理尚无本地确认记录的关卡。已核实的本地提交始终保留；提交状态不确定的关卡优先回查原报告，避免重复提交。目标分数是优化目标，不保证最终成绩达到该值。

队列按本地账号、平台身份和选择范围保存。暂停、关闭窗口或重启后，再次右键同一范围即可恢复；关闭时等待执行线程保存进度。登录过期会停止队列，在窗口重新登录同一账号后继续。失败题、未接入题型、缺少模型或参考音色均单独显示原因，其他关卡继续执行；读取目录失败的课程也会列入日志和汇总，重试时重新查询完整目录。

选择有问题的关卡后点击「打开所选关卡」，可以在原音频挑战窗口处理待复核题、调整策略或改用本地音频。导入新的账号参考 WAV 需回到主窗口的「账号与音色」。当前支持的题型见下方列表；t12 等尚未接入的关卡会明确显示「未支持」，整任务会保留为待处理状态。

## 三种语音引擎

| 引擎 | 使用方式 | 模型下载 | 账号参考 WAV |
| --- | --- | --- | --- |
| Edge TTS | 联网合成，新配置默认 | 无需 | 不使用 |
| YourTTS | 本地模型，保留原有支持 | 单独下载 | 需要 |
| XTTS v2 | 本地模型，保留原有支持 | 单独下载 | 需要 |

Edge 可选择英文音色和语速，候选阶段使用同一音色的不同原生语速。网络失败会明确报错，不会自动换成其他引擎。选择本地模型时，基础生成和候选阶段按需加载，候选阶段复用模型实例，结束后释放进程和显存。切换引擎不会清空其他模型路径或各账号的音色文件。

「单词生成」仍提供旧版 Windows 策略：使用首个已安装的美式英语系统音色，基础语速为 -5，前后分别补 200 ms、350 ms 静音；拒识时以其他原生语速重新合成。这条路径不使用账号参考音色，缺少系统音色时会提示安装语音包或切换策略。新配置选择「使用所选引擎」，已有单词策略保持不变。

本地模型可以在「环境与下载」自动准备独立的 Python 3.11 CPU 环境和模型，也可以手动填写已安装 `coqui-tts` 的 `python.exe`。自动安装使用固定版本的 `src/fif_oral/resources/requirements-tts.lock.txt`，已验证 `coqui-tts 0.24.3`、`transformers 4.48.3`、PyTorch 2.9.1+cpu 的组合。运行设备仍可选择自动、CUDA 或 CPU；自动安装只准备 CPU 依赖，已有 CUDA 环境可以继续使用。

- YourTTS 目录需要 `config.json`、`model_file.pth`、`model_se.pth`、`config_se.json`、`speakers.json`、`language_ids.json`。
- XTTS v2 目录需要 `config.json`、`model.pth`、`vocab.json`、`speakers_xtts.pth`。
- 后续使用 PyInstaller 打包 GUI 时，需包含 `src/fif_oral/audio/speech_worker.py`、`src/fif_oral/resources/dependency-manifest.json`、`src/fif_oral/resources/requirements-tts.lock.txt`、`src/fif_oral/resources/assets/`、`src/fif_oral/web/static/` 及 Edge TTS 依赖。运行时本地模型与其 Python 环境仍单独存放。当前提供源码启动入口，尚未生成 EXE 安装包。

生成音频会按题目文本、模型文件内容和参考音色的哈希缓存。停止后再次启动会复用已完成音频；已开始评测的挑战始终使用原音频继续，避免换模型后混用评分。模型日志保存在 `data/speech-worker.log`。

候选机制将重新生成与后期修正分开。发音不匹配或有效但低分时，Windows 通过自身语速 0、-2、2、-4 重新合成；神经模型使用不同随机种子与原生语速生成。无语音、截幅等录音异常才尝试补静音、降低音量。默认目标 80 分、每题 3 个评测候选，可在模型设置修改或关闭。不会修改引擎分数或拒识标记。

目标分数用于提前停止优化。预算耗尽后仍可采用分数最高、未拒识的有效候选；若没有有效候选，则保持待复核，不会将拒识结果按 0 分提交。

「允许的备用模型」默认关闭。开启后只使用用户已经下载的指定模型和账号参考音色，不会静默切换到另一种音色。每个模型按需加载并在工作结束后释放。

英文单词还可使用「上下文后备」：在载句中以同一音色合成，送评测取得唯一目标词的 10 ms 帧边界，保留首尾辅音余量并截取目标词，再按原单词单独评测。对齐结果异常、词边界缺失或不唯一时不会使用该截取结果。载句及对齐 XML 也会保存；对齐与目标词评测合计占 2 个预算，通常需要将每题预算提高到 5。对齐只是定位依据，最终是否有效仍由独立单词评测决定。

预算按题目、基础音频和生成策略持久化，点击继续、重新打开窗口或重启应用不会清零。准备送评测前先记录预算占用，连接结果不确定时也不会无限重送。已拒识的音频按哈希排除；生成出相同音频也不再调用评测。可在模型设置明确增加预算，或调整待复核题的生成策略。预算与目标分数不参与生成策略标识，因此调整目标分数不会重置已用次数。

通过的候选与原始评测 XML 单独保存，校验音频、XML 和参考文本后可在 24 小时内复用；生成成功本身不代表通过评测。本地检查会排除空音频、数字静音、明显截幅和超长录音，不会通过裁切静音误删首尾辅音。

每种录音修正都从原 WAV 生成，调整不会叠加；全部尝试的 XML、实际输入音频、所选方案和逐题分数会保留。数字、货币、小数与序数按旧版规则转成朗读文本，评测参考文本保持题目原文。

已接入英文朗读 t1、t2、t3、t4、t10、t11、t13 题型。题目数量、角色和原始下标参与结果构造。检测到听力选择题时会明确列为未支持；听力的原生提交、t12 填空对话、开放式题目及其他语言的评分逻辑需要继续适配。

关闭窗口或停止后可以恢复。提交超时会进入「回查成绩」，通过报告中的录音路径确认是否已入库。完成后点击「新一轮」可开始新的挑战。

没有有效候选的题目进入「待复核」，其他题继续处理。窗口显示已验收题与待复核题；点击「重试待复核题」只处理未通过题。待复核时允许更改模型设置、增加预算或重新选择参考音色，已验收结果保持不变。手动音频模式可以只替换失败题的文件。全部题目有效之前不会提交关卡。

## 接口逆向与协议实现说明

本项目使用的是从 FIF 口语客户端行为中整理的业务接口，**不是基于官方公开且承诺兼容的开发者 SDK**。协议研究涉及前端资源、页面路由与运行时网络请求分析，并参考了旧版 `fif_gui` 的行为。相关参考项目及许可列在 [THIRD_PARTY.md](THIRD_PARTY.md)；当前已实现行为以本仓库源码为准。

### 已实现的调用链

| 环节 | 当前实现 | 主要代码 |
| --- | --- | --- |
| 登录与会话 | 使用用户提供的凭据完成 CAS / SSO HTTP 登录，处理图片验证码、平台跳转及会话有效期 | [api/auth.py](src/fif_oral/api/auth.py)、[api/client.py](src/fif_oral/api/client.py) |
| 任务与题目查询 | 查询当前账号可访问的任务、课程、关卡、题目、挑战配置与历史报告 | [api/client.py](src/fif_oral/api/client.py) |
| 语音合成 | 使用 Edge TTS，或加载用户另行准备的 YourTTS / XTTS v2 模型与参考音色 | [audio/speech.py](src/fif_oral/audio/speech.py)、[audio/edge.py](src/fif_oral/audio/edge.py)、[audio/speech_worker.py](src/fif_oral/audio/speech_worker.py) |
| 在线评测 | 从 FIF 口语获取评测授权地址和应用标识，将音频转换为 16 kHz 单声道 PCM 后送讯飞评测，解析返回的 XML | [audio/assessment.py](src/fif_oral/audio/assessment.py) |
| 上传与提交 | 从 FIF 口语获取临时 OSS 凭据，上传录音与评测 XML，再提交挑战结果 | [challenge.py](src/fif_oral/challenge.py)、[api/client.py](src/fif_oral/api/client.py) |
| 结果确认与恢复 | 持久化逐题进度，按报告及录音路径核对本次提交；结果不确定时先回查 | [challenge.py](src/fif_oral/challenge.py)、[automation.py](src/fif_oral/automation.py) |

桌面版直接调用这些 Python 业务模块；WebUI 是同一套业务模块的本机操作界面。运行流程不需要加载 FIF 口语网页、执行其页面脚本或注入浏览器麦克风，但登录、评测和提交仍需要连接对应的在线服务。

### 实现边界与验证范围

- **沿用账号权限。** 登录令牌由平台签发，评测授权和上传临时凭据从当前会话获取。项目不生成伪造登录令牌，也不内置通用账号、长期评测私钥或可供他人共用的上传凭据。
- **保留真实评测结果。** 候选策略通过重新合成或修正音频后再次评测来选择结果，不改写评测分数或拒识标记；生成成功、评测通过和平台确认提交是不同阶段。
- **按已适配题型执行。** 当前支持范围为前文列出的英文朗读题型。听力原生提交、t12 等仍未接入；未支持的关卡会明确标记，不能据此宣称全题型可用。
- **区分分析记录与运行证据。** 协议分析中的静态推断不等于端到端验证。`tests/` 中部分 FIF 口语、TTS、评测及上传端点使用模拟实现，用于验证流程与恢复逻辑；测试通过或本地生成有效 WAV，不代表任意真实账号、题目或平台版本均已验证。
- **接口可能变化。** 路径、字段、授权方式、风控及评测规则由服务方控制；前端或后端更新后，客户端可能需要重新适配。项目没有官方接口稳定性保证。

如发现接口权限或敏感信息问题，请先对复现材料脱敏，避免在公开 Issue 中发布可用凭据、其他账号数据或完整鉴权请求。提出问题时可提供客户端版本、题型、脱敏错误信息及可复现步骤。

## 启动

Windows x64 可双击 `setup.cmd` 启动 WebUI。首次自动准备本项目目录内的 Python 3.11 与应用依赖，无需预先安装 Python。默认不下载大型 TTS 模型。启动桌面版或只安装不启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -Mode desktop
powershell -NoProfile -ExecutionPolicy Bypass -File .\bootstrap.ps1 -NoLaunch
```

安装不会修改系统 PATH、系统 Python 或持久执行策略。也可手动创建应用环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e "."
.\.venv\Scripts\python.exe -m fif_oral
```

源码开发环境也可使用 `uv sync --frozen --extra web` 安装锁定依赖，随后以 `uv run --no-sync fif-oral` 或 `uv run --no-sync fif-oral-web` 启动。

### 安装 Python wheel

[Releases](https://github.com/Dorouthas/FIF-Desktop/releases) 提供 wheel 与源码包。已有 Python 3.11–3.13 时，可在虚拟环境中安装下载的 wheel：

```powershell
python -m pip install "./fif_oral_desktop-1.0.0b2-py3-none-any.whl[web]"
fif-oral
# 或启动本机 WebUI
fif-oral-web
```

首次公开版本为 Beta，当前未提供 EXE 安装包。大型语音模型仍单独下载。

创建主密码后添加账号。选择「登录」，在原生窗口输入账号密码，并在平台要求时手动填写图片验证码。客户端通过 HTTPS 建立会话并查询数据。也可使用平台已签发的口语访问令牌。每个账号会话分别保存在本次运行的内存中。

账号密码登录需要平台通过 HTTP 跳转提供口语会话。触发其他校验，或平台要求由网页脚本完成会话交接时，窗口会显示相应错误。

## 自动下载与诊断

桌面版和 WebUI 的「环境与下载」共用安装器：可准备 Edge 组件、FFmpeg、可选本地 TTS CPU 环境，以及 YourTTS、XTTS v2 模型。下载成功后自动配置路径，保留原来选择的语音引擎。模型下载前需阅读并勾选其许可：YourTTS 为 CC BY-NC-ND 4.0，XTTS v2 为 Coqui Public Model License；详见 `THIRD_PARTY.md`。

下载来源和固定版本记录在 `src/fif_oral/resources/dependency-manifest.json`。FFmpeg 来自 Gyan 官方发布及镜像，模型来自 Coqui 官方发布或固定 Hugging Face 快照。下载支持取消和续传，按 SHA-256 校验后再启用；YourTTS 压缩包解压后逐文件校验。缓存保存在 `data/downloads/`，独立 Python、运行依赖和模型保存在 `data/runtime/`、`data/models/`。可选本地环境建议预留至少 6 GB，另加模型所需空间。

双击 `diagnose.cmd` 执行本地诊断。联网合成测试需显式传入 `--online`，只合成固定测试句，不登录 FIF 口语、不上传录音或提交成绩：

```powershell
.\.venv\Scripts\python.exe -m fif_oral.environment.doctor --online
```

报告保存到 `data/diagnostics/doctor.json`；Edge 测试 WAV 保存到同目录。

## 本机 WebUI

WebUI 与桌面版共用 Python 业务模块、加密账号库、音色文件、模型设置和单关/批量队列进度。前端为本地 HTML、CSS 和 JavaScript 模块，后端为 FastAPI，无需 Node.js 构建。页面采用简洁的浅色界面，适配桌面与窄屏布局。

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[web]"
.\.venv\Scripts\python.exe -m fif_oral.web
```

也可双击 `start_webui.cmd`。启动后在浏览器打开 `http://127.0.0.1:8765`，用原有主密码解锁账号库。首次使用且没有账号库时，页面会要求创建主密码。服务默认只监听本机，可用 `--port 8766` 修改端口，或用 `--data-dir D:\Other\FiFData` 使用独立数据目录。

首版包含账号增删改、原生 HTTP 登录与图片验证码续登、账号参考 WAV 导入/试听/默认音色管理、任务/课程/关卡查询、参考音频播放、三级右键全自动完成、历史队列、暂停/恢复、逐关状态及运行日志。三种引擎均可选择，环境与下载窗口支持安装、取消和联网测试；也可手动填写运行服务电脑上的模型与 FFmpeg 路径。任务执行前可选择账号音色和是否跳过已达目标的关卡；Edge 且未启用本地备用模型时不需要音色文件。

关闭网页不会停止后台队列；点击「暂停」后保存进度，重新打开页面可继续。服务本身退出时也会请求暂停并等待工作线程保存。运行日志保留最近 400 条在内存中；重启服务后保留的是持久化队列状态、逐题进度和报告信息。一次只执行一个自动队列；执行时需先暂停，再修改账号、音色和模型配置。

桌面版和 WebUI 共享 `accounts.lock`，使用相同数据目录时只能运行其中一个入口。平台访问令牌留在后端内存中，账号查询不会返回保存的密码。页面通过同源请求和 HttpOnly 会话 cookie 访问本机接口。

当前 WebUI 仍未接入麦克风逐题录音、手工替换失败题音频或开启全新一轮单关挑战，这些操作继续使用桌面版。自动执行题型与桌面版相同，t12 等显示为未支持，不会当成完成。

验证命令：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
node --check src/fif_oral/web/static/app.js
```

`tests/web_preview.py` 是独立浏览器联调入口，使用临时账号库和模拟 FIF 口语、TTS、评测及上传端点，不读取生产账号或提交真实成绩。它与正式启动入口分开。

## 本地数据

源码运行默认使用项目根目录的 `data/`；通过 wheel 安装时默认使用用户数据目录。可使用 `FIF_ORAL_DATA_DIR` 或 `--data-dir` 指定位置。以下路径均相对于所选数据目录。

- `data/accounts.json` 保存经 Scrypt 派生密钥和 AES-GCM 加密的账号与音色配置。
- `data/voices/` 保存导入的 PCM WAV 副本。账号库记录相对路径、哈希和默认音色。
- `data/recordings/` 保存本地答题录音，按账号、任务和关卡分开。
- `data/challenges/` 保存逐题进度、已上传录音路径、报告编号、本次分数和逐题原始评测 XML。登录令牌与 OSS 临时凭据只保存在内存中。
- `data/queues/` 保存任务、课程、关卡范围的自动执行队列、设置快照、参考音色校验、状态与报告编号，不保存密码和访问令牌。
- `data/speech.json` 保存语音引擎、两个本地模型的目录、TTS Python 环境、设备和 Edge 音色/语速配置；旧配置不会自动切换引擎。
- `data/web.json` 保存 WebUI 的 FFmpeg 路径；其他语音配置与桌面版共用 `speech.json`。
- `data/generated/` 按账号保存生成的 WAV 与缓存校验信息。
- `data/adaptive/` 按账号、任务和关卡保存真实评测历史及派生音频。文本、基础音频或模型策略变化后使用独立记录。
- `data/candidates/` 保存候选账本、生成参数、已用预算、音频哈希与评测验收缓存。
- 迁移时一起复制账号文件和音色目录。用原主密码解锁。
